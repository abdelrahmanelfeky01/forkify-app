# 🍴 Forkify — Recipe Search App

A recipe application that lets you search over 1,000,000 recipes, adjust servings, bookmark favorites, and even upload your own custom recipes.

## ✨ Features
- 🔍 Search from 1,000,000+ recipes via the Forkify API
- ⚖️ Dynamically adjust ingredient quantities based on servings
- 🔖 Bookmark favorite recipes (saved in localStorage)
- ➕ Upload and share your own custom recipes
